Settings

Store profile, billing details and data connection.

Store profile

Each product carries its own GST rate (set when you add/edit it) since different categories fall under different GST slabs. This is only the default used for new products, and can be overridden per line in POS or Orders.

Appearance

Customize how the app looks — changes apply instantly and are saved with your other settings.

Billing details (shown on invoices)

Used to guess Intra-state vs Inter-state when you pick a customer in POS or Orders — sales to this state default to CGST+SGST, everywhere else defaults to IGST. Always adjustable per sale.

Database connection

Runs on local browser storage by default. Optionally connect your own Supabase project to sync data to a real database.

Local data only

See supabase-schema.sql in this project for the matching table definitions.

Connect an existing store

Bring products in from a platform you already sell on. Export a CSV there, then import it here — SKUs, prices, stock and categories map in automatically.

S
Shopify
Shopify Admin → Products → Export → "All products" as CSV.
W
WooCommerce / WordPress
WooCommerce → Products → Export, leave columns on "All columns".
+
Any other system
Generic CSV/Excel with SKU, Name, Price, Stock columns — same importer used in Inventory.

Products are matched and updated by SKU — importing the same file twice updates prices/stock rather than duplicating. Column names from Shopify (Variant SKU, Variant Price...) and WooCommerce (SKU, Regular price...) are recognized automatically alongside plain SKU/Price/Stock headers.
